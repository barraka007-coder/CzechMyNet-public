# Checklist before making this *presentation* repository public

- [ ] Confirm the GitHub account and destination repo are correct.
- [ ] Keep the **existing development repository private**. Do not change its visibility.
- [ ] Publish **only** the contents of this folder, not the application source, build artifacts, logs, `.env` files, tokens, or project workspace.
- [ ] Review all three images for personal information, private IPs, usernames, project secrets or sensitive local details. The included development screenshot shows network counts, not traffic data exports.
- [ ] Verify `assets/logo-cmn.png` is the approved branding; do not regenerate/modify its design.
- [ ] Confirm feature/status wording is still current.
- [ ] Add social links **only after** verifying the actual URL. Do not use guessed links.
- [ ] Leave Releases empty and do not publish installers.
- [ ] Do not add an open-source LICENSE file until license terms are chosen. Public visibility alone does not grant reuse rights.
- [ ] Optional: restrict Issues/Discussions until ready to respond; GitHub settings can be changed later.
